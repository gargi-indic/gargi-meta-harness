BINDING spec for #48 (M4.5 planner API). Read the issue body (scratchpad issue48.md) first and follow its Scope/Acceptance criteria, amended by the maintainer's standing rule and the verified facts below. STOP and report instead of guessing if something conflicts and you cannot resolve it.

MAINTAINER RULE: GITHUB IS THE STATE STORE (SQLite is a cache/outbox/event log rebuilt by `harness sync`). Consequences for this API:
1. Proposals: use harness/planner/proposal_store.py from #46 (`save_proposal`, `get_proposal`, `update_proposal`, `restore_proposal_mirror`): drafts and edits are persisted GitHub-first (marker comments on the control issue + a ledger summary) with the local `proposals` table as the mirror. Do not add a second proposals table or migration (the issue's "add the same migration here" is obsolete: it exists). A `PUT` edit must go through the same path; rapid edits must coalesce (outbox `coalesce_key`) instead of spamming GitHub. Decide and document how reads behave while a save is still queued (for example a pending-draft marker in `meta` returned by GET until the mirror is promoted; keep `rev` monotonic and make `If-Match`/412 work on it). If this proves much larger than expected, STOP and report the options.
2. Job state must survive a restart: derive it from the proposal's status (drafting/ready/invalid/creating/created, stored in the proposal summary in the ledger and mirrored) and from `materialize`'s own markers, not from in-memory dicts alone. In-memory asyncio tasks only run the work; "same job on repeated approve" is derived from the proposal status + run key (`plan_run_key` in harness/planner/materialize.py). `GET /api/planner/jobs/{job_id}` can use job_id == proposal id + kind.

- The Approve endpoint requires: validation clean, plan approval `APPROVED` (not PENDING/STALE: 409 with the reason and `note`), rev unchanged since last validation; it then runs `materialize` through the outbox as a background task and returns 202. Approving twice returns the same job. `control_issue` comes from the repo config unless given.
