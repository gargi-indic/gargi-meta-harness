Routes `/campaigns`, `/board`, `/inbox`, `/runs`, `/playbooks` → `<Page title="Campaigns">` etc. (placeholder text "Not built yet."); `/` redirects to `/campaigns`; unknown → a `Page title="Not found"`.

Clicking a link closes the menu.
- `api/client.ts`: `class ApiError extends Error { status: number; detail: string }`; `apiGet<T>(path: string, init?: {signal?: AbortSignal}): Promise<T>`, `apiPost<T>(path: string, body: unknown): Promise<T>`; `fetch(path, {credentials: "same-origin", headers: {Accept: "application/json"} (+ `Content-Type: application/json` on POST)})`; non-2xx → parse JSON `{detail}` if possible (string detail, or `JSON.stringify` of a non-string detail, else `res.statusText`) and throw `ApiError`. 204 → `undefined`.
- `api/sse.ts`: `useEventStream(handler: (e: {seq: number; type: string; data: unknown}) => void, types?: string[])`: one `EventSource("/api/events")` per mount, closed on unmount; listens to `message` and to each named type in `types` (default `EVENT_TYPES`); parses `data` JSON and `lastEventId` → seq; keeps the latest handler in a ref (no reconnect on handler change); browser handles reconnect + Last-Event-ID. Export `EVENT_TYPES = ["run.updated","step.updated","inbox.changed","issue.updated"] as const`.
- `api/queries.ts`: `createQueryClient()` (retry 1, staleTime 5000), `queryKeys` = `{runs: ["runs"], run: (id) => ["runs", id], inbox: ["inbox"], issues: ["issues"], campaigns: ["campaigns"]}`, `useInvalidateOnEvents()` using `useEventStream`: `run.updated` → invalidate `["runs"]` (prefix, covers run detail); `step.updated` → `["runs", data.run_id]` when present else `["runs"]`; `inbox.changed` → `["inbox"]`; `issue.updated` → `["issues"]` and `["campaigns"]`. Mount it once in `App`.
- `vite.config.ts`: react plugin; `server.proxy` for `/api` and `/auth` → `http://127.0.0.1:7777` (GlobalConfig's default port; the issue's 8765 is wrong); `build.outDir: "dist"` (= `web/dist`, what #23's `harness serve` serves); `server.host: "127.0.0.1"`.
- `scripts/export_playbook_schema.py`: imports `playbook_json_schema()` and writes `web/src/generated/playbook.schema.json` with `json.dumps(schema, indent=2) + "\n"`; path relative to the script (`Path(__file__).resolve().parents[1]`); optional `--check` flag that exits 1 if the file differs. No re-implementation of the schema.
