SPEC for harness/publish.py (exact):
1. `PublishResult` frozen dataclass exactly as in the issue; exceptions `PublishError(Exception)` and `ProtectedPathViolation(PublishError)` with a `.paths: list[str]` attribute; message lists paths only.
2. `async def publish_worktree(*, wt, gh: GitHub, repo, issue_number, issue_title, body_extra="", draft=False, protected_paths=(), git="git", author=None) -> PublishResult | None` with these steps in order:
   a. Branch check FIRST: `wt.branch` must match `^harness/<issue_number>-[a-z0-9-]+$` and `validate_ref(wt.branch)`, else `PublishError` (also refuse if branch equals wt.base). No git/GitHub call before this.
   b. `git status --porcelain` (cwd=wt.path) and `git rev-list --count <wt.base-ref>..HEAD` where the base ref is `refs/remotes/origin/<wt.base>` if it exists else `<wt.base>` (validate with validate_ref). Both empty/0 -> return None, no GitHub call.
   c. Changed paths = union of `git diff --name-only <base-ref>...HEAD`, `git diff --name-only` , `git diff --name-only --cached`, and `git ls-files --others --exclude-standard`, using `-z` and splitting on NUL; also include rename sources. If any matches `match_protected` -> raise `ProtectedPathViolation(paths)` BEFORE any `git add`/commit/push.
   d. If working tree is dirty: `git add -A` then commit with message `#<n>: <title>` using `-c user.name=... -c user.email=...` only when `author` is given (else rely on git config, falling back to `gargi-harness` / `harness@localhost` if none configured). Skip the commit when nothing is staged/dirty.
   e. `git push --force-with-lease origin <branch>:<branch>`; never push anything but the validated branch. Errors -> `PublishError` with stderr passed through a redactor that strips any `://user:token@` credentials and any token-like string (Bearer/ghp_/github_pat_); never include env or the GitHub token.
   f. `head_sha = git rev-parse HEAD`.
   g. `gh.pulls_for_head(repo, branch, state="open")`; if one exists return it with `created=False`. Otherwise `gh.create_pull(repo, f"#{n}: {title}", branch, wt.base, body=f"Closes #{n}\n\n{body_extra}".rstrip()+"\n" if body_extra else f"Closes #{n}", draft=draft)`, `created=True`.
   `changed_files` = sorted unique list from step c (computed again after commit via `git diff --name-only <base-ref>...HEAD` is fine).
3. `async def push_revision(wt, *, message: str, git="git", author=None, protected_paths=()) -> str`: same branch check and protected-path check, commit all changes with `message` (error `PublishError` if there is nothing to commit), push with force-with-lease, return the new head sha. No PR creation.
